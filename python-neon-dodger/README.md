# Neon Dodger (Python + pygame)

An arcade survival game: dodge falling neon meteors, collect energy orbs, and see how long you last. The game gets faster every 15 seconds.

## Run it
```bash
pip install pygame
python neon_dodger.py
```

## Controls
| Key | Action |
|---|---|
| ← → or A D | Move |
| Space | Dash (with cooldown) |
| P | Pause |
| R | Restart after game over |
| Esc | Quit |

## Features
- Particle explosions, a motion trail, and screen shake on hit
- 3 lives with a brief invincibility window after each hit
- Parallax starfield that speeds up with each level
- Best score tracked during the session
