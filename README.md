# Claude Projects

A collection of small projects across five languages and engines, by **John Francis**.

| Project | Language / Engine | What it is |
|---|---|---|
| [java-library-system](java-library-system) | Java | Console library system showing all four OOP pillars |
| [python-neon-dodger](python-neon-dodger) | Python + pygame | Neon arcade survival game with particles and a dash |
| [web-galaxy-explorer](web-galaxy-explorer) | HTML / JS Canvas | Interactive 3D spiral galaxy with supernovas |
| [unity-coin-collector](unity-coin-collector) | Unity, C# | Third-person coin-collecting game scripts |
| [roblox-obby-kit](roblox-obby-kit) | Roblox, Luau | Obby scripts with checkpoints, saving, and moving platforms |

Each folder has its own README explaining how to run it.
